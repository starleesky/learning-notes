## 🔧 执行流程

### Step 1: 架构设计

**输出：**
```markdown
## 系统架构

### 核心组件

1. **组件 A** - 职责
2. **组件 B** - 职责
3. **组件 C** - 职责

### 组件关系

```
┌──────────┐     ┌──────────┐
│ 组件 A   │────▶│ 组件 B   │
└──────────┘     └──────────┘
```
```

---

### Step 2: 数据流图（ASCII）

**输出：**
```markdown
## 数据流

### 正常流程

```
用户请求 → API Gateway → 业务逻辑 → 数据库 → 响应
```

### 错误流程

```
用户请求 → API Gateway → [错误] → 错误处理 → 错误响应
```
```

---

### Step 3: 状态机设计

**输出：**
```markdown
## 状态机

### 状态

- **State A** - 描述
- **State B** - 描述
- **State C** - 描述

### 转换

```
State A ──[Event 1]──▶ State B
State B ──[Event 2]──▶ State C
State C ──[Event 3]──▶ State A
```
```
