### 文章 1: OpenAI Harness Engineering 深度解析

- **来源:** CSDN / OpenAI Blog
- **链接:** https://blog.csdn.net/zinss26914/article/details/159650887
- **发布日期：** 2026-02-11

**核心内容：**
OpenAI 发布工程博客《Harness engineering: leveraging Codex in an agent-first world》，公开一套让 Agent 稳定参与开发的工程组织方式。

**关键数据：**
- 5 个月、100 万行代码、0 行人工手写
- 初始 3 名工程师驱动，后扩展至 7 人
- 累计约 1500 个 PR

**Harness Engineering 核心模块：**
1. 上下文/知识
2. 工具/权限
3. 验证/约束
4. 状态/记忆
5. 可观测性/反馈
6. 人类接管/生命周期

**关键公式：** `0.95^20 ≈ 36%` — 多步 Agent 成功率指数衰减，缺少验证与恢复机制是核心问题。

**核心理念：** `Humans steer. Agents execute.`
