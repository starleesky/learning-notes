## 📊 自主执行流程

### 每日流程

```
09:00 ─┬─ 每日安全检查
       ├─ 每日简报（AI 动态 + GitHub + Twitter）
       ├─ 每日学习（技术文档抓取）
       ├─ Twitter 监控（L1/L2 账号）
       └─ GitHub Trending（Top 20）

14:00 ─┴─ 任务执行（执行待办清单高优先级任务）

18:00 ─┬─ 进度追踪（统计完成率）
       ├─ 自动汇报（飞书推送）
       └─ 进化日报（总结今日）
```

### 任务执行逻辑

```yaml
task-executor:
  读取：docs/todo-list-*.md
  筛选：
    - 优先级：🔴 高 > 🟡 中 > 🟢 低
    - 截止时间：临近优先
    - 状态：待执行
  执行：
    - 文档类：直接创建/编辑
    - 代码类：调用 coding-agent
    - 测试类：运行测试命令
  更新：
    - 标记完成：✅
    - 记录工时
    - 提交 Git
  推送：
    - 飞书通知
```
